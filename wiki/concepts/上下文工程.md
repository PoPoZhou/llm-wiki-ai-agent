# 上下文工程（Context Engineering）
上下文（context）＝ LLM 一次能「看到」的所有文字，包含指令、對話、工具結果。
- 它是有限的：「Context, therefore, must be treated as a finite resource with diminishing marginal returns.」[S4]
- 原則：只放最需要的：「finding the smallest possible set of high-signal tokens」[S4]
- 技巧：只記住「去哪裡找」，需要時再查：「maintain lightweight identifiers (file paths, stored queries, web links, etc.)」[S4]
延伸：[[長時間任務]]、[[多代理系統]]
